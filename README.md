# IMPULSE DATA LAB v3.0

Открытый интерактивный комплекс математического, эконометрического и физического моделирования на **R + Shiny**.
Главная идея — **проверяемость**: код, показанный в терминале Code Inspector, — это ровно тот код, который выполняет расчёт, и его можно скачать одним нажатием и воспроизвести вне приложения.

Разработан для студенческого трека «ИИ-ПРОРЫВ: молодые кадры для развития региона» (холдинг Т1, КубГУ).

## Возможности

| Блок | Модули |
|---|---|
| Эконометрика и стохастика | 1. ARIMA-прогноз · 2. Монте-Карло / геометрическое броуновское движение |
| Нелинейная динамика и физика | 3. Аттрактор Лоренца (ОДУ, RK4) · 4. Орбиты Кеплера (уравнение Кеплера) · 5. Осциллятор с затуханием (ОДУ) |
| Матрицы | 6. Собственные значения и векторы · 7. Сингулярное разложение (SVD) |
| Статистика и топология | 8. Распределения · 9. Корреляция и регрессия · 10. Сетевые графы |
| **Реальные данные** | **11. Свои данные:** загрузка CSV, описательная статистика, бэктест ARIMA на отложенной части (MASE, sMAPE, RMSE, покрытие 95% интервала, тест Льюнга–Бокса) |

Дополнительно:
- **Code Inspector** — исполняемый код модуля + кнопка **«Скачать .R»**.
- **Вкладка «Задания»** — 5 заданий с автопроверкой (Лоренц, Кеплер, осциллятор, SVD, GBM).
- **«Матрица расчётов»** — числа, стоящие за графиком, для всех модулей.
- **Воспроизводимость** — seed вынесен в интерфейс.
- **Офлайн** — внешних ресурсов (CDN, облачных API) нет.

## Запуск

Нужен R ≥ 4.0.

```r
install.packages(c("shiny", "plotly", "forecast", "deSolve"))
shiny::runApp()          # из корня репозитория
```

### Свои данные
Выберите модуль 11 → «Свой CSV». Разделитель (`,` или `;`), десятичный знак и кодировка (UTF-8 / Windows-1251) определяются автоматически. Нужен числовой столбец минимум из 40 наблюдений. Примеры: `data/demo_monthly_sales.csv`, `data/demo_monthly_sales_ru.csv` (русский формат Excel). Данные примеров — **синтетические**.

## Проверка

```sh
Rscript tests/smoke.R
```
Тест выполняет код всех модулей без UI и проверяет математику (уравнение Кеплера, A·v = λ·v, корреляция выборки, симметрия графа, убывание ошибки SVD с ростом ранга, чтение CSV, автопроверка заданий). Тот же тест запускается в GitHub Actions при каждом push.

## Ограничения (честно)

- Это учебно-исследовательский прототип, а не замена BI-системе; один процесс Shiny обслуживает пользователей последовательно.
- Модуль 11 использует `auto.arima`; для редких или короткоживущих рядов и сложных структурных сдвигов нужна отдельная проверка модели.
- Модули 1–10 работают на синтетических данных — это сознательный выбор для демонстрации математики.
- Проект единым файлом `app.R` без Shiny-модулей и без `renv`; см. дорожную карту.

## Дорожная карта

- Shiny-модули и `renv.lock`, Docker-образ.
- Сравнение ARIMA / ETS / NNETAR и rolling-origin бэктест.
- Экспорт отчёта (Quarto / PDF), сохранение состояния параметров по URL.
- Вынос тяжёлых расчётов в асинхронные задачи (`future` / `promises`).
