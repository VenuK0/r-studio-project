# Технический паспорт: IMPULSE DATA LAB v3.0

## 1. Общие сведения
- **Назначение:** интерактивный учебно-исследовательский комплекс математического, эконометрического и физического моделирования с проверяемыми расчётами.
- **Контекст:** студенческий трек «ИИ-ПРОРЫВ: молодые кадры для развития региона» (Т1, КубГУ).
- **Лицензия:** MIT, репозиторий GitHub `VenuK0/Impulse-Data-Base`.
- **Использование ИИ:** Google Gemini (v1–v2.3), Claude (аудит, v2.4–v3.0); журнал — `docs/AI_AUDIT.md`.

## 2. Стек
R ≥ 4.0 · Shiny · Plotly · `forecast` · `deSolve`. Внешних сервисов и CDN нет; расчёты выполняются локально.

## 3. Архитектура (один файл `app.R`, логические слои)
1. **Генератор кода** `build_code()` — шаблон исполняемого R-кода модуля с параметрами из интерфейса.
2. **Исполнение** `run_code()` — выполняет тот же текст в изолированном окружении.
3. **Представление** — графики Plotly и таблицы «Матрица расчётов» читают результаты окружения.
4. **Аудит** — Code Inspector показывает исполненный код; «Скачать .R» отдаёт его файлом.
5. **Обучение** — вкладка «Задания» с автопроверкой по тем же параметрам.

## 4. Модули
1 ARIMA · 2 GBM/Монте-Карло · 3 Лоренц (ОДУ, RK4) · 4 Кеплер · 5 Осциллятор (ОДУ) · 6 Собственные значения · 7 SVD · 8 Распределения · 9 Корреляция и регрессия · 10 Сетевые графы · **11 Свои данные (CSV, описательная статистика, бэктест ARIMA)**.

## 5. Верификация
- `tests/smoke.R` — выполнение всех модулей и проверка математических свойств; запускается в GitHub Actions.
- Время расчёта измеряется в сессии и выводится в KPI (заранее заданных значений нет).
- Seed вынесен в интерфейс: любой результат воспроизводим.

## 6. Ограничения
Прототип: один процесс Shiny, без аутентификации; нет Shiny-модулей, `renv` и Docker (см. дорожную карту в README). Модули 1–10 работают на синтетических данных, модуль 11 — на реальных.
